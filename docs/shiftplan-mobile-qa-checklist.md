# ShiftPlan Mobile QA Checklist

Use this before inviting more private beta testers on iPhone. Test in Safari first, then from the Home Screen shortcut if installed.

| Check | Pass/Fail | Notes |
| --- | --- | --- |
| App login accepts a valid beta email and access code. |  |  |
| Add to Home Screen instructions are easy to find and follow. |  |  |
| Dashboard first impression feels compact and the primary action is obvious. |  |  |
| Saved preference/default examples are clear on mobile. |  |  |
| Weekly request form is readable without awkward horizontal scrolling. |  |  |
| Quick chips fit on mobile and fill the intended fields without submitting. |  |  |
| Tell ShiftPlan your week freeform input is visible and understandable. |  |  |
| Generate plan button is easy to find after saving a weekly request. |  |  |
| Generated timeline is readable day by day. |  |  |
| Interactive checklist groups by day and tap states work. |  |  |
| Calendar download starts an .ics download/import flow. |  |  |
| Feedback form is usable after reviewing a saved plan. |  |  |
| Copy Week Summary, Copy Plan, and Copy Checklist buttons work. |  |  |
| Dark theme contrast is readable in normal and dim lighting. |  |  |

Safety spot check:
- Confirm safety language is still present before generation and around saved plans.
- Confirm generated output stays focused on lifestyle and routine planning.
- Confirm no medical, diagnosis, treatment, medication, workplace safety, mental health, emergency, or healthcare guidance is requested or displayed.
