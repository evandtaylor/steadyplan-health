# ShiftPlan Content Strategy Skill

## Purpose

Use this skill for marketing/content docs, social copy, swipe-video scripts, beta CTAs, and campaign planning.

## When To Use

- Social post ideas and scripts.
- Faceless swipe-video concepts.
- Waitlist, beta invite, or DM copy.
- Profile/bio positioning.
- Campaign image prompt packs.

## Must-Read Context

- `docs/codex-skills/shiftplan-core-rules.md`
- `docs/shiftplan-content-bank.md` when extending content.
- `docs/shiftplan-social-profile-copy.md` when extending bio/CTA copy.
- Current public-site positioning.

## Rules

- Keep claims lifestyle/routine only.
- No medical, treatment, fatigue treatment, burnout treatment, sleep disorder, workplace safety, medication, supplement, healthcare, or mental health claims.
- Keep tone human, concrete, and not too salesy.
- Private beta means invite/waitlist, not public account creation.
- Avoid implying guaranteed outcomes.
- Do not change runtime app or website unless explicitly requested.

## Required Checks

- Run `npm run lint`.
- Run `npm run build`.
- Confirm docs only when the task is documentation-only.
- Scan for unsafe medical/treatment claims.
- Confirm no Stripe or app/admin behavior changes.

- Content artifact:
- Files changed:
- Audience/use case:

- Lint/build:
- Recommended next content action:

## Common Mistakes To Avoid

- Positioning ShiftPlan as health advice.
- Overpromising better sleep, less fatigue, or burnout relief.
- Writing generic productivity content instead of shift-schedule-specific content.
- Using public signup language before public accounts exist.
