# ShiftPlan App Store Readiness Checklist

This checklist defines what should be true before ShiftPlan invests in a native iOS app.

## Prerequisites Before Native App

- 10-20 private beta users have tried `/app`.
- 5-10 generated plans have been reviewed by real testers.
- At least a few testers show repeat weekly interest.
- Top complaints are identified.
- Pricing interest is clearer, especially around $9/month.
- The web app flow is stable on mobile Safari.
- Saved preferences, request reuse, feedback, and checklist behavior are validated.
- Safety, privacy, and terms language are current for customer-side AI generation.

## First iOS MVP Scope

- Login
- Preferences
- Create weekly request
- Generate plan
- View plan
- Interactive checklist
- Feedback
- Use last week as starting point

## Not-Yet Items

- Push notifications
- Widgets
- Apple Health
- Wearables
- Community
- Calendar sync
- Native reminders
- Customer billing portal

## App Store Listing Needs

- App name
- Subtitle
- Screenshots
- Privacy policy URL
- Support URL
- Terms URL
- App preview video later

## Suggested Positioning

ShiftPlan is an AI weekly planner for shift workers. It helps organize shifts, meals, workouts, errands, appointments, family responsibilities, and weekly priorities into a realistic routine plan.

Avoid medical positioning. Do not describe ShiftPlan as a healthcare app, sleep treatment app, fatigue treatment app, or workplace safety tool.

## Native iOS Decision Gate

Native iOS should become the next build only when:

1. Beta users return for more than one weekly plan.
2. The most valuable mobile workflow is obvious.
3. The generated plan format is stable.
4. Checklist usage is meaningful.
5. Feedback shows a clear reason the web app is not enough.

Until then, continue improving the mobile-first web app and private beta loop.
